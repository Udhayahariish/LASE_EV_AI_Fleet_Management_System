# LASE EV – AI-Powered EV Fleet Management System

## Overview
LASE EV is a Flask-based Electric Vehicle Fleet Management platform with AI-powered analytics, dashboard monitoring, authentication, database integration, and chatbot support.

## Key Features
- EV Fleet Dashboard
- User Login & Authentication
- AI/ML Prediction Model
- Chatbot Assistance
- Flask Backend Architecture
- SQL Database Integration
- Data Analytics & Reporting
- Responsive User Interface
- CSV/Data Processing Support

## Technology Stack
### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Python
- Flask

### Database
- SQL Database (SQLite)

### Machine Learning
- Pickle (.pkl) Models
- Predictive Analytics
